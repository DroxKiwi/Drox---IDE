## Analyse du projet KDDS — Drox IDE

### 📋 Vue d'ensemble
Il s'agit d'un **site landing page immersif** pour **Drox IDE**, un assistant IA dédié au code. Le projet utilise une esthétique "Abyss" inspirée des profondeurs océaniques et de la bioluminescence.

---

### 🏗️ Architecture technique

| Couche | Outil |
|--------|-------|
| Framework | **Next.js 16** (App Router, React Server Components) |
| Langage | **TypeScript** strict |
| UI / CSS | **Tailwind CSS v4**, shadcn/ui, Radix UI primitives |
| Animations | **Framer Motion** (parallaxe, transitions) + Canvas natif pour Aurora |
| Icônes | Lucide React |

---

### 📂 Structure du dépôt

```
site-kdds/                          ← racine du repo (KDDS)
├── README.md                       ← documentation complète bilingue FR/EN
└── app-kdds-main/                  ← application Next.js
    ├── package.json                ↕ dépendances & scripts
    └── src/
        ├── app/                    ← App Router Next.js
        │   ├── layout.tsx          ↕ shell racine (fonts, providers)
        │   ├── page.tsx            ↕ route / → Home (landing)
        │   ├── globals.css         ↕ design system "Abyss" complet (~15 Ko)
        │   └── background-animations.css
        ├── components/             ← composants React
        │   ├── app-shell.tsx       ↕ conteneur principal + sidebar fixed
        │   ├── sidebar.tsx         ↕ navigation latérale glassmorphism (fixed, 260px)
        │   ├── theme-provider.tsx  ↕ thème light/dark (localStorage)
        │   ├── home-content.tsx    ↕ page d'accueil : 2 sections scroll-snap
        │   ├── aurora-sync-background.tsx ← fond Aurora canvas + particules CSS
        │   ├── override-ui/        ↕ composants sur-mesure
        │   │   └── abyssal-portal-button.tsx  ← CTA "Portail Abyssal" (vortex, membrane)
        │   └── ui/                 ← shadcn/ui (Button, Separator, ScrollArea, Collapsible…)
        ├── lib/                    ← hooks & contextes partagés
        │   ├── use-parallax.ts     ↕ hook parallaxe souris (framer-motion springs)
        │   ├── use-scroll-snap.ts  ↕ progression scroll entre sections + particules de transition
        │   ├── spotlight-context.tsx
        │   └── utils.ts            ← cn() / class merging
```

---

### 🎨 Design System "Abyss AI"

Le design system est entièrement codé dans `globals.css` avec une palette océanique :

| Token | Couleur | Rôle |
|-------|---------|------|
| `--abyss-deep` | `#01040d` | Fond principal — noir profond des abysses |
| `--bio-primary` | `#22d3ee` (cyan) | Lumière bioluminescente principale |
| `--accent-start/end` | Indigo → Violet (`#6366f1` → `#a855f7`) | Dégradés d'accentuation |

**Classes utilitaires notables :** `.card-abyss` (glassmorphism), `.btn-bio-alive` (morphing organique), `.title-bio` (gradient + pulse-glow + focus-deep), `.scanline-abyss` (ligne sonar).

---

### 🧩 Composants clés

1. **AuroraSyncBackground** — Canvas unique dessinant 3 couches d'ondes sinusoïdales bioluminescentes synchronisées au scroll, avec transition douce des couleurs entre sections (lerp progressif), halo central pulsant, scan line descendante et optimisation CPU (pause après 600ms d'inactivité).

2. **HomeContent** — Page à 2 sections en `scroll-snap` :
   - **Section Hero** : titre animé "Drox IDE" avec parallaxe 3D (rotateX/Y), tagline, CTA Abyssal Portal Button
   - **Section Téléchargement** : cartes par plateforme (Windows/macOS/Linux) + footer avec liens sociaux

3. **Sidebar** — Navigation latérale fixe (`260px`) en glassmorphism avec sections collapsibles ("Outils IA"), branding KDDS et version "Abyss Edition".

4. **AppShell** — Conteneur principal intégrant la sidebar fixed et injectant les providers (Theme + Spotlight).

| Fonctionnalité | Statut |
|---------------|--------|
| Landing page "Abyss" | ✅ Implémenté |
| Design system complet (CSS) | ✅ Implémenté |
| Composants sur-measure (`override-ui/`) | ✅ Implémenté |
| Thème light/dark | ✅ Implémenté |

---

### 🧠 Points remarquables

- **Animation Aurora optimisée** : le canvas utilise un DPR réduit (`max 1.5x`) et se met en pause après inactivité de scroll pour économiser CPU/GPU.
- **Parallaxe multi-intensité** : chaque section a sa propre intensité de parallaxe (`heroX` ×50, `section2X` ×35) avec perspective dynamique qui varie du scroll (1200px → 800px).
- **Transition Aurora par section** : l'IntersectionObserver détecte la section visible et déclenche un lerp progressif des couleurs du canvas.
- **Effet loupe sur les CTA** : les boutons principaux grossissent (`scale: 1→1.4→1`) pendant la transition de scroll entre sections.

## Analyse du projet KDDS — Drox IDE

### 📋 Vue d'ensemble
Il s'agit d'un **site landing page immersif** pour **Drox IDE**, un assistant IA dédié au code. Le projet utilise une esthétique "Abyss" inspirée des profondeurs océaniques et de la bioluminescence.

---

### 🏗️ Architecture technique

| Couche | Outil |
|--------|-------|
| Framework | **Next.js 16** (App Router, React Server Components) |
| Langage | **TypeScript** strict |
| UI / CSS | **Tailwind CSS v4**, shadcn/ui, Radix UI primitives |
| Animations | **Framer Motion** (parallaxe, transitions) + Canvas natif pour Aurora |
| Icônes | Lucide React |

---

### 🎨 Design System "Abyss AI"

Le design system est entièrement codé dans `globals.css` avec une palette océanique :

| Token | Couleur | Rôle |
|-------|---------|------|
| `--abyss-deep` | `#01040d` | Fond principal — noir profond des abysses |
| `--bio-primary` | `#22d3ee` (cyan) | Lumière bioluminescente principale |
| `--accent-start/end` | Indigo → Violet (`#6366f1` → `#a855f7`) | Dégradés d'accentuation |

**Classes utilitaires notables :** `.card-abyss` (glassmorphism), `.btn-bio-alive` (morphing organique), `.title-bio` (gradient + pulse-glow + focus-deep), `.scanline-abyss` (ligne sonar).

---

### 🧩 Composants clés

1. **AuroraSyncBackground** — Canvas unique dessinant 3 couches d'ondes sinusoïdales bioluminescentes synchronisées au scroll, avec transition douce des couleurs entre sections (lerp progressif), halo central pulsant, scan line descendante et optimisation CPU (pause après 600ms d'inactivité).

2. **HomeContent** — Page à 2 sections en `scroll-snap` :
   - **Section Hero** : titre animé "Drox IDE" avec parallaxe 3D (rotateX/Y), tagline, CTA Abyssal Portal Button
   - **Section Téléchargement** : cartes par plateforme (Windows/macOS/Linux) + footer avec liens sociaux

3. **Sidebar** — Navigation latérale fixe (`260px`) en glassmorphism avec sections collapsibles ("Outils IA"), branding KDDS et version "Abyss Edition".

4. **AppShell** — Conteneur principal intégrant la sidebar fixed et injectant les providers (Theme + Spotlight).

---

### 🧠 Points remarquables

- **Animation Aurora optimisée** : le canvas utilise un DPR réduit (`max 1.5x`) et se met en pause après inactivité de scroll pour économiser CPU/GPU.
- **Parallaxe multi-intensité** : chaque section a sa propre intensité de parallaxe (`heroX` ×50, `section2X` ×35) avec perspective dynamique qui varie du scroll (1200px → 800px).
- **Transition Aurora par section** : l'IntersectionObserver détecte la section visible et déclenche un lerp progressif des couleurs du canvas.
- **Effet loupe sur les CTA** : les boutons principaux grossissent (`scale: 1→1.4→1`) pendant la transition de scroll entre sections.
