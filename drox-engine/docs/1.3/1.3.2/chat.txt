## 📁 Structure globale

Le projet est une application **Next.js** (App Router) nommée `app-kdds-main`, située dans un dossier du même nom. La branche principale est `main`.

### Stack technique
- **Framework :** Next.js 16.2.4 (App Router, Server Components)
- **Langage :** TypeScript strict (`noImplicitAny`, `strictNullChecks`, alias `@/*`)
- **UI :** React 19 + Tailwind CSS v4 + shadcn/ui (Radix UI primitives)
- **Animations :** Framer Motion
- **Icônes :** Lucide React

### Organisation du code (`src/`)

| Dossier | Rôle |
|---|---|
| `app/` | App Router — layout, page d'accueil, CSS global, routes API v1 |
| `components/ui/` | Composants shadcn : button, card, dialog, input |
| `components/` | Composants métier : shell app, contenu home, thème (provider/toggle), fond animé, suiveur de souris |
| `lib/` | Utilitaires : `utils.ts` (`cn()`), contexte spotlight, hooks (`useMousePosition`, `useParallax`) |
| `types/` | Types TypeScript (vide pour l'instant) |
| `generated/` | Code généré (vide pour l'instant) |

### Points notables
- **Thème dark/light** via un provider dédié + toggle
- **Animations de fond** avec CSS personnalisé + composant animé + effet suiveur de souris
- **API v1** structurée mais pas encore implémentée (`src/app/api/v1/` est vide)
- **Docker** configuré pour le dev (`docker-compose.dev.yml`)
- Le projet semble en phase initiale : la page d'accueil redirige vers `HomeContent`, les dossiers `types/` et `generated/` sont vides
