# Atelier

Petit outil en ligne de commande pour chiffrer une commande de pièces.

Le catalogue est dans `data/pieces.json`. Le code métier est dans le paquet `atelier`. Le point d'entrée est `main.py`.

```text
python main.py devis PL-04 2 PL-11 1
```

La doc d'architecture est dans `docs/architecture.md`. Le format du catalogue est dans `docs/catalogue.md`.
