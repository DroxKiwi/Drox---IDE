# Pas d’initiative

- **Ne pas** inventer ni appliquer un patch « pour aider » sans accord explicite.
- **Uniquement** appliquer du code **vu / décidé avec l’utilisateur** (brief, plan validé, ou « fais X » clair).
- En cas de doute : **proposer** (diagnostic, options) — **ne pas coder** tant que ce n’est pas validé.
- Interdit sans accord : forcer le modèle via gates durs, changer une policy produit, refactors hors scope, « filets » inventés.

Les conseils / nudges soft restent une option fortement recommandée ; **pas** d’obligation d’étape imposée au modèle sauf demande explicite.
