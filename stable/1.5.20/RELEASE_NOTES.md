# Drox IDE 1.5.20

## Nouveautés

- Chat IDE natif : Commit / Commit & Push, Changes en activité Sidebar.
- Mute des paramètres LLM non supportés + contrôles reasoning effort / thinking budget.
- Correctif ordre des messages `system` OpenAI (Qwen / LiteLLM).
- Canal Releases sur ce dépôt (`Drox---IDE`), plus `Drox---IDE---OR`.
- Documentation moteur : [`docs/engine/`](../../docs/engine/README.md).

## Prérequis

- Windows 10+ (64 bits)
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
- [Ollama](https://ollama.com/) (recommandé) ou endpoint OpenAI-compatible
