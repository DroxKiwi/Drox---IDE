# Drox IDE 1.6.8

Un média trouvé dans le répertoire n'entre plus dans le contexte. `file_read` et `grep` renvoient une fiche (nom, chemin, poids, type) pour une image, un audio ou une vidéo. Une sortie de terminal qui n'est pas du texte devient la même fiche.

Les images collées dans le chat restent envoyées au modèle. Le SVG et les sources texte restent lisibles.

Installeurs Windows et Linux.
